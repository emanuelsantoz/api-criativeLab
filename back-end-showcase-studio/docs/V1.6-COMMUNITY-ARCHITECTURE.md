# v1.6.0 — Comunidade independente

## Objetivo

Permitir que uma pessoa sem vínculo com uma instituição cadastrada publique um projeto e sua apresentação no Criative Lab, mantendo o fluxo institucional atual sem qualquer regressão.

## Princípios que não mudam

- O envio institucional continua público, vinculado a curso, turma, semestre e contexto de submissão.
- Nenhum dado institucional é removido ou migrado para uma estrutura nova.
- Todo projeto continua passando por curadoria antes de se tornar público.
- Projetos da comunidade são analisados somente por `ADMIN` da plataforma; coordenadores e professores seguem moderando seus contextos institucionais.
- Senhas não serão criadas para membros da comunidade. O acesso usa um link temporário enviado ao e-mail informado.

## Modelo de dados

| Elemento | Decisão |
| --- | --- |
| Conta | Reutilizar `User`; não criar uma segunda entidade de pessoa. |
| Papel comunitário | `Role.COMMUNITY_MEMBER`. |
| Autenticação | `CommunityAccessToken`, com hash do segredo, expiração curta, uso único e limite de requisições. |
| Origem do projeto | `Project.origin`: `INSTITUTIONAL` ou `COMMUNITY`. |
| Vínculo acadêmico | `courseId` e `semesterId` passam a ser opcionais apenas para origem `COMMUNITY`. |
| Propriedade | O projeto comunitário sempre possui `createdById`; o dono pode editar enquanto estiver pendente ou com ajustes solicitados. |
| Feed | `Project.publishedAt` é gravado na aprovação e ordena novidades públicas. |

## Fluxos

### Institucional — preservado

1. Pessoa escolhe uma instituição, curso/turma e contexto abertos.
2. Envia o projeto sem criar conta.
3. A curadoria institucional revisa; pedidos de ajuste seguem usando o token de submissão já existente.

### Comunidade — novo

1. Pessoa informa o e-mail em **Entrar na comunidade**.
2. A API envia um link temporário; a mesma resposta é dada para e-mails novos ou existentes, evitando enumeração de contas.
3. Ao validar o link, a API cria (se necessário) uma conta `COMMUNITY_MEMBER` e entrega uma sessão.
4. A pessoa completa o perfil e envia o projeto sem curso, turma ou semestre.
5. O projeto entra em `PENDING_REVIEW`, com `origin = COMMUNITY` e `createdById` definido.
6. Apenas o administrador da plataforma delibera. O autor acompanha e edita na área pessoal até a decisão final.

## Fases de entrega

1. **Fundação de dados** — migração aditiva, origem do projeto, data de publicação e token de acesso comunitário.
2. **Conta comunitária** — solicitação e validação de link por e-mail, sessão, perfil mínimo e limites de segurança.
3. **Publicação comunitária** — formulário próprio, upload direto ao R2 e curadoria exclusiva do administrador.
4. **Área pessoal** — projetos enviados, edição de pendentes/ajustes, métricas, likes e feedbacks recebidos.
5. **Feed público** — publicações recentes ordenadas por `publishedAt`, filtros por origem e links para projetos.
6. **Experiência e migração** — escolha clara entre envio institucional e comunidade, ajuda, tours, testes e monitoramento.

## Contratos de API planejados

| Método | Rota | Propósito |
| --- | --- | --- |
| `POST` | `/community/auth/request-link` | Solicita um link temporário por e-mail. |
| `POST` | `/community/auth/verify` | Consome o token e inicia a sessão comunitária. |
| `GET/PATCH` | `/community/me` | Lê e atualiza o perfil do membro. |
| `GET/POST` | `/community/projects` | Lista projetos próprios e cria envio comunitário. |
| `GET/PATCH` | `/community/projects/:id` | Lê e edita projeto próprio quando permitido. |
| `GET` | `/feed` | Retorna projetos aprovados por data de publicação. |

## Regras de segurança

- Token aleatório de alta entropia; somente o hash é armazenado.
- Expiração de 15 minutos, uso único e invalidação de tokens anteriores do mesmo e-mail.
- Limites por IP e por e-mail nas solicitações de link.
- Nenhuma rota informa se o e-mail já possui conta.
- Somente o proprietário autenticado edita projeto de comunidade; aprovados e rejeitados não são editáveis sem nova ação de curadoria.
- O e-mail do responsável não entra em respostas públicas nem no feed.
